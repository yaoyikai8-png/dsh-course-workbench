# 全课件知识点笔记（course-notes）

和 `course-outline` 的区别：提纲给骨架，这份给**血肉**——每个知识点要能独立读懂，
不依赖课件原文。它的目标是「只看这份笔记就能把课重新过一遍」。

## 环境约定

- 课程根目录由插件的 `courseRoot` 配置项决定（默认 `~/Documents/courses`），每门课一个子文件夹；
  通常本技能在课程项目的会话里被调用，会话工作目录就是该课程文件夹，直接以它为准。
- 课件通常为 `.pptx`（也可能有 `.pdf`）
- 产物目录：`<课程目录>/<课程名>笔记和复习/`
  （笔记、提纲、期末复习**都放这一个文件夹**，不要再建 `笔记/`、`提纲/`）

## 工作流

1. **确定课程**：用户点名则用之；否则从当前会话工作区推断，或列目录让用户选。
2. **清点课件**：递归列出该课程下所有 `.pptx` / `.pdf`，按讲次排序，**记录总数 N**。
3. **逐讲提取**：用 `office-pptx` 技能读取每份课件的全部文字（标题、正文、表格、备注）。
   一份一份处理，不要跳读。提取失败（扫描版/纯图片）的讲次单独记下。
4. **提炼知识点**：对每一讲，把课件内容转成知识点条目。判断标准：
   - **概念**：给出一句话定义 + 为什么需要它（解决什么问题）+ 一个例子或类比
   - **公式**：写出公式，逐个符号说明含义和单位，说明适用条件
   - **过程/机制**：按步骤拆开，写清每一步的输入和输出
   - **分类/对比**：做成小表格，列出判别依据
   - 课件里明确标注「重点」「考点」「思考题」的，用 `> **考点**` 引用块标出
5. **写笔记**：输出到 `<课程目录>/<课程名>笔记和复习/<课程名>-知识点笔记.md`：

   ```markdown
   # <课程名> 知识点笔记

   > 覆盖课件：M/N 讲（列出未覆盖的讲次与原因）
   > 生成时间：YYYY-MM-DD

   ## 目录
   - [第 1 讲 <标题>](#第-1-讲-标题)
   ...

   ## 第 1 讲 <标题>

   ### 1.1 <知识点名>
   **定义**：…
   **为什么**：…
   **要点**：
   - …
   > **考点**：…（课件有标注时）

   ### 1.2 <知识点名>
   ...

   > **本讲参考资料**：文献/延伸阅读/图表出处（课件里有才写，没有就省略这一行）

   ## 附：跨讲概念对照
   | 概念 | 首次出现 | 后续发展 | 易混点 |
   |---|---|---|---|
   ```

6. **回报**：两个文件路径（md + pdf）、总字数、覆盖讲次（M/N）、跳过的讲次及原因、以及
   「哪些讲次内容偏少、可能需要补看课件原文」的提示。**不要把全文贴进对话**。

## 课件更新后（增量）

每次运行都**重新扫描目录**，新加的课件自动进入清单。目标文件已存在时：

1. 先读已有的 `<课程名>-知识点笔记.md`，解析已覆盖的讲次；
2. 新讲次 → 只补写这些讲次的章节，插到「跨讲概念对照」之前；
3. 已覆盖但文件改过（修改时间晚于笔记）→ 只重写该讲；
4. 其余章节原样保留，**不要整篇重写**；
5. 动手前告诉用户「将新增 X 讲、重写 Y 讲」，等确认；
6. 更新开头「覆盖课件：M/N」与目录。

## 输出格式

- 先写 Markdown（`.md`）——右侧预览读的就是它。
- 再把它转成同名 PDF（**不再产出 docx**）：

  ```powershell
  python "$env:USERPROFILE\.dsh\tools\md2pdf.py" "<课程目录>\<课程名>笔记和复习\<课程名>-知识点笔记.md" "<课程目录>\<课程名>笔记和复习\<课程名>-知识点笔记.pdf"
  ```

  脚本自带中文字体，不依赖 Word / LibreOffice。它只认 Markdown 的一个子集：
  标题、段落、无序/有序列表、表格、`**加粗**`、行内代码、代码块、引用块。
  别用 HTML 标签、脚注、mermaid、图片语法——PDF 里会原样变成文字。
- 转换后确认 PDF 存在且非空，**不要删掉 md**。

## 约束

- **只写课件里有的内容**。需要背景补充时，明确标注「补充（非课件内容）」。
- 提取不到文字的讲次，写 `> 本讲课件为图片/扫描版，未能提取文字，需人工补看`，
  不要用常识填空。
- 笔记可以长（这是它的用途），但不要复制粘贴课件原文成段；
  要用自己的话重述，保留关键术语的原文表述。
- 目标文件已存在时先询问是否覆盖。
- 课程讲次很多（> 20 讲）时，先做前 5 讲并给用户看样例，确认风格后再继续。
- 提取课件时产生的临时脚本、中间文本、导出的图片，一律放到 `$env:TEMP` 下的临时目录，用完删掉；不要留在课程文件夹里。
