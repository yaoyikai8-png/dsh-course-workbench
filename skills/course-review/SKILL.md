# 期末复习（course-review）

产出一份**能直接拿去背和刷**的复习材料。它有两个不可分割的部分：
前面的总结负责「把课重新讲一遍」，文末的**习题与解答**负责「知道自己会不会」。
只写总结不写题，等于没复习。

## 环境约定

- 课程根目录由插件的 `courseRoot` 配置项决定（默认 `~/Documents/courses`），每门课一个子文件夹，
  内含按讲次编号的课件与「第X次作业」子文件夹。
- 通常本技能在某个课程项目的会话里被调用，会话工作目录就是该课程文件夹；
  若不在课程文件夹中，先问用户要处理哪门课。
- 产物目录：`<课程目录>/<课程名>笔记和复习/`（与笔记、提纲同一个文件夹）。

## 工作流程

1. **清点材料**：列出该课程文件夹中全部 `.pptx`/`.ppt`/`.pdf`/`.docx`（按讲次编号排序），
   特别标出**试卷、真题、习题集、作业答案**这类文件——它们是习题部分的第一手来源。
   把清单和拟定范围先告诉用户，请其确认（全部复习 / 只复习部分讲次）。
   用户已在界面上勾选过文件时，**只处理勾选的那些**，不要再扩大范围。
2. **提取内容**：用 `office-pptx` 提取课件文本；pdf 用可用的 PDF 读取方式；
   docx 用 `office-docx`。讲次多时分批处理。
   提取时**单独记一份题目清单**：每看到一页有题目（思考题、例题、随堂练习、案例讨论、
   计算题、选择题），就记下「原文题干 + 所在文件 + 页码/讲次 + 是否已给答案」。
   这一步漏了，文末的习题就会缺斤少两。
3. **写总结**（第一部分）：按**知识板块**重组，不按讲次平铺：
   - 开头一张「全局框架」表：板块 | 核心问题 | 对应讲次 | 重要度
   - 每个板块：核心概念、公式/图表含义、典型判据、易混点对比表、考点频率（★～★★★）
   - 显式写出跨讲关系（哪几讲在讲同一件事、怎么递进）
   - 引用图表/数据时注明「来自《文件名》第 N 页」
4. **写习题与解答**（第二部分，必须在文末，不能省）：见下节要求。
5. **写考点速查表**（第三部分）：一张表，考点 | 所属板块 | 出现次数 | 掌握程度建议。
6. **落盘**：先写 `<课程目录>/<课程名>笔记和复习/<课程名>-期末复习.md`，
   再转成同名 PDF：

   ```powershell
   python "$env:USERPROFILE\.dsh\tools\md2pdf.py" "<课程目录>\<课程名>笔记和复习\<课程名>-期末复习.md" "<课程目录>\<课程名>笔记和复习\<课程名>-期末复习.pdf"
   ```

   脚本自带中文字体，不依赖 Word / LibreOffice。它只认 Markdown 的一个子集：
   标题、段落、无序/有序列表、表格、`**加粗**`、行内代码、代码块、引用块。
   别用 HTML 标签、脚注、mermaid、图片语法——PDF 里会原样变成文字。
   转换后确认 PDF 非空，**不要删掉 md**（预览用它）。
7. **汇报**：两个文件路径 + 覆盖讲次 M/N + **「共整理 X 道题（课件原有 A / 往年真题 B / 预测 C）」**。
   不要把全文贴进对话。

## 习题与解答的要求

题源必须**穷尽**，四类都要有：

1. **课件里原有的题目**：勾选的每份文件逐页扫一遍，PPT/PDF 里的思考题、例题、课堂练习、
   随堂测验、案例讨论题，全部收进来，注明出处（文件名 + 页码/讲次）。
   课件已给答案的，答案照录并可补一句解析；没给答案的，自己写。
2. **往年试卷 / 习题集**：勾选文件里有试卷、真题、习题答案的，**逐题**整理，标注「真题」与年份；
   同一考点重复出现的，题后注明「同考点出现 N 次」。
3. **模型预测题**：根据考点频率、易混点、老师强调的重点自己出题，标注「预测」。
4. **综合题**：至少 3 道跨板块大题，模拟压轴。

每道题都要给**完整解答**，不能只给答案要点：

- 计算题：公式 → 代入过程 → 单位 → 结果
- 简答题：分点作答，每点一两句
- 论述/综合题：先给答题框架（采分点），再给一段示范作答
- 选择题：正确选项 + 每个错误选项错在哪

按题型分组：名词解释 → 选择/判断 → 填空 → 简答 → 计算 → 论述/综合。
每组开头一句「该题型分值占比与答题策略」。

## 约束

- 目标文件已存在时，先告知用户并确认是否覆盖。
- 任何单处原文摘录 ≤3 行，用自己的话重组。
- 课件提取失败的讲次要明确列出「未覆盖讲次」，不要静默跳过。
- **不要编造真题**。不是从文件里读到的题，一律标「预测」。
- 若用户想要 LaTeX/A4 版速查表且已安装 look-tongji-notes，可建议用其 CheatingSheetTemplate，但不强制。
- 提取课件时产生的临时脚本、中间文本、导出的图片，一律放到 `$env:TEMP` 下的临时目录，用完删掉；不要留在课程文件夹里。
