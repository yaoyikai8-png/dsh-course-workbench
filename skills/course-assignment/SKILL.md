# 课程作业/报告助手

## 环境约定

- 课程根目录由插件的 `courseRoot` 配置项决定（默认 `~/Documents/courses`），每门课一个子文件夹；
  作业通常放在课程文件夹的`第X次作业`子文件夹。
- 本技能通常在某个课程项目的会话里被调用，会话工作目录就是该课程文件夹；若不在课程文件夹中，先问用户是哪门课的作业。

## 工作流程

1. **定位题目**：优先查看会话工作目录下最新的`第X次作业`子文件夹；也可由用户直接粘贴题目。读题支持 docx/pdf/图片（图片用 read_image 看）。
2. **确认要求**：向用户确认三件事——提交格式（docx / 手写拍照 / md）、有没有老师给的模板或格式要求、截止时间是否紧迫。作业文件夹里有模板文件时**必须以模板为准**。
3. **先提纲后正文**：先给出答案提纲（每题用什么方法、关键步骤、需要的输入数据），等用户确认再写完整答案；用户赶时间时可跳过确认，但要在回复中说明。
4. **起草答案**：理论题写完整推导过程，标注依据（"据第X讲课件"）；计算题给出每一步公式代入与单位；图题先描述判读依据再给结论。
5. **生成交付文件**：
   - docx：用 `office-docx` skill 生成，写入 `第X次作业/答案-第X次.docx`；公式用 Word 能显示的格式（Office Math 或清晰的文本表达）。
   - md：写入 `第X次作业/答案-第X次.md`。
6. **汇报**：回复给出文件路径 + 各题一句话结论。

## 约束（重要）

- **实验/数据类作业**：数据必须来自用户提供的真实记录；缺数据的字段一律写 `【待填：…】` 并在回复里列出待填清单。**绝不编造实验数据或观测结果**。
- 不确定的假设必须显式写"假设：…"。
- 引用课件内容时标注讲次，引用外部资料时给出来源。
- 不替用户在作业系统里提交；只生成本地文件。
