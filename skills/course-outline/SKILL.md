# 课程提纲（course-outline）

把一门课的全部课件压成一份**可通读的骨架**，同时**到课件里翻资料**：哪一讲引了哪本书、
哪张图出自哪篇文献、老师标了哪些"延伸阅读"。它回答的是「这门课的整体结构 + 每讲该配什么资料」，
而不是「考试要背什么」（后者用 `course-review`）。

## 环境约定

- 课程根目录由插件的 `courseRoot` 配置项决定（默认 `~/Documents/courses`），每门课一个子文件夹；
  通常本技能在课程项目的会话里被调用，会话工作目录就是该课程文件夹，直接以它为准。
- 每门课一个子目录，课件通常为 `.pptx`（也可能有 `.pdf`）
- 产物目录：`<课程目录>/<课程名>笔记和复习/`
  （提纲、笔记、期末复习**都放这一个文件夹**，不要再建 `提纲/`、`笔记/`）

## 工作流

1. **确定课程**：用户点名则用之；否则列出课程根目录下的子目录让用户选，
   或从当前会话的工作区路径推断。不要自行猜测。
2. **清点课件**：列出该课程目录（含子目录）下所有 `.pptx` / `.pdf`，
   按文件名里的讲次编号排序。**记录总数 N**，后面要用。
3. **提取文本**：优先用 `office-pptx` 技能读取每份 PPT 的文字；
   `.pdf` 用可用的 PDF 读取方式。逐讲提取标题、各级小标题、要点条目。
   提取失败（扫描版/纯图片）时跳过并记录，不要编造内容。
4. **翻资料**（这一步不能省）：每讲都扫一遍，找这几类东西——
   - 参考文献 / 书目 / 教材章节（通常出现在页脚、最后一页、或"参考"字样附近）
   - 老师标注的「参考资料」「延伸阅读」「推荐阅读」「拓展」
   - 图表、照片、数据的**出处**（"引自…""数据来源：…"）
   - 案例、实例、野外/实验记录
   - 课件里的外部链接（网址、DOI、文献名）
   逐条记录：**讲次 + 资料名 + 类型 + 出处（第几页/第几张幻灯片）**。
   一条都没找到就写「未发现」，**不要用常识补全，也不要编文献**。
5. **写提纲**：输出到 `<课程目录>/<课程名>笔记和复习/<课程名>-课程提纲.md`，结构固定为：

   ```markdown
   # <课程名> 课程提纲

   > 覆盖课件：M/N 讲（列出未覆盖的讲次）

   ## 一、课程总览
   （3–6 句话：这门课的研究对象、主线、各部分如何衔接）

   ## 二、分讲提纲
   ### 第 1 讲 <标题>
   - **核心问题**：这一讲要解决什么
   - **关键概念**：概念A、概念B、概念C（只列名，解释留给笔记）
   - **与其他讲的衔接**：承接哪一讲、为哪一讲铺垫
   - **相关资料**：文献/延伸阅读/图表出处（没有就写「未发现」）

   ### 第 2 讲 <标题>
   ...

   ## 三、概念地图
   （用嵌套列表画出概念之间的从属/因果/对比关系，10–20 个节点即可）

   ## 四、资料索引
   | 讲次 | 资料 | 类型 | 出处 |
   |---|---|---|---|
   | 第 3 讲 | 某某等，2019，期刊名 | 文献 | P12 |
   | 第 5 讲 | 某教材 第 4 章 | 教材 | P3 备注 |
   ```

6. **回报**：两个文件路径（md + pdf）、覆盖讲次数（M/N）、跳过的讲次及原因、**资料索引条数**。

## 课件更新后（增量）

每次运行都**重新扫描目录**，新加的课件会自动进入清单，不需要改任何配置。目标文件已存在时：

1. 先读已有的 `<课程名>-课程提纲.md`，解析它已经覆盖了哪些讲次；
2. 对比当前目录：**新讲次**（文件是新的）→ 只补写这些讲次；
3. **已覆盖但文件改过**（按修改时间晚于提纲）→ 只重写该讲；
4. 其余讲次原样保留，**不要整篇重写**；
5. 动手前先告诉用户「将新增 X 讲、重写 Y 讲」，等确认；
6. 更新开头「覆盖课件：M/N」一行与「资料索引」。

## 输出格式

- 先写 Markdown（`.md`）——右侧预览读的就是它。
- 再把它转成同名 PDF（**不再产出 docx**）：

  ```powershell
  python "$env:USERPROFILE\.dsh\tools\md2pdf.py" "<课程目录>\<课程名>笔记和复习\<课程名>-课程提纲.md" "<课程目录>\<课程名>笔记和复习\<课程名>-课程提纲.pdf"
  ```

  脚本自带中文字体，不依赖 Word / LibreOffice。它只认 Markdown 的一个子集：
  标题、段落、无序/有序列表、表格、`**加粗**`、行内代码、代码块、引用块。
  别用 HTML 标签、脚注、mermaid、图片语法——PDF 里会原样变成文字。
- 转换后确认 PDF 存在且非空，**不要删掉 md**。

## 约束

- 提纲是**骨架**：每讲 3–6 条要点，不要展开成长篇；需要细节时提示用户改用 `course-notes`。
- 只写课件里真实存在的内容；提取不到就标注「未提取到」，不要用常识补全。
- 资料必须能在课件里指出位置；**编造文献比空着更糟**。
- 目标文件已存在时先询问是否覆盖，不要静默重写。
- 单份 PPT 超过 200 页时，先只取标题层与资料页，并在回报里说明。
- 提取课件时产生的临时脚本、中间文本、导出的图片，一律放到 `$env:TEMP` 下的临时目录，用完删掉；不要留在课程文件夹里。
