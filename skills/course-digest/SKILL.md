# 课件消化流水线

## 环境约定

- 课程根目录由插件的 `courseRoot` 配置项决定（默认 `~/Documents/courses`），每门课一个子文件夹，
  内含按讲次编号的课件 PPT。
- 本技能通常在某个课程项目的会话里被调用，会话工作目录就是该课程文件夹；若不在课程文件夹中，先问用户处理哪门课。
- 产物目录：`<课程目录>/<课程名>笔记和复习/`（与提纲、期末复习同一个文件夹）。

## 工作流程

1. **确定讲次**：用户指定了文件/讲次则用之；否则选取课程文件夹中**文件修改时间最新**的一个 `.pptx`/`.ppt`，向用户确认。
2. **提取内容**：用 `office-pptx` skill 提取该课件的全部文本与图形结构；office skill 不可用时改用 python-pptx（先用 load_workspace_dependencies 获取 Python 路径）。
3. **生成讲次笔记**：写入 `<课程名>笔记和复习/第N讲-主题.md`（N 取课件编号，主题用 2-6 个字概括），内容依次为：
   - 本讲在课程中的位置（承接/引出什么）
   - 知识结构（小节标题 + 要点，中文为主，术语附英文）
   - 重点概念与图件解读（PPT 截图以"图N：说明"引用，不复制图片）
   - 可能的考点（考试视角 3-8 条）
   - 遗留问题区（初始为空，供课后补充）
   - 全文控制在 150 行以内。
4. **转 PDF**（同名，保留 md）：

   ```powershell
   python "$env:USERPROFILE\.dsh\tools\md2pdf.py" "<课程目录>\<课程名>笔记和复习\第N讲-主题.md" "<课程目录>\<课程名>笔记和复习\第N讲-主题.pdf"
   ```

   脚本自带中文字体，不依赖 Word / LibreOffice；只认标题、段落、列表、表格、`**加粗**`、
   行内代码、代码块、引用块，别用 HTML/mermaid/图片语法。
5. **更新索引**：维护 `<课程名>笔记和复习/INDEX.md`，每讲一行：`- [第N讲-主题](第N讲-主题.md)：一句话摘要`。已有条目不重复追加。
6. **汇报**：回复给出两个文件路径 + 10 行以内的内容摘要，不粘贴全文。

## 约束

- 笔记文件已存在时不覆盖，先问用户（覆盖 / 另存）。
- 单处原文摘录 ≤3 行，用自己的话重组。
- 课件是图片型/无文本时，明确告知"该讲无法提取文本"，建议用户用 office-render 渲染成图后再看图整理。
- 提取课件时产生的临时脚本、中间文本、导出的图片，一律放到 `$env:TEMP` 下的临时目录，用完删掉；不要留在课程文件夹里。
